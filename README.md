# React-test

A React test project featuring the Studios3000Nav navigation component.

## Project Structure

```
├── src/
│   ├── studios3000_nav.jsx  # Main navigation component
│   └── index.js             # Example usage
├── public/
│   └── index.html           # HTML template
└── package.json             # Project dependencies
```

## Studios3000Nav Component

The `studios3000_nav.jsx` component provides a simple, reusable navigation bar for React applications.

### Features

- Clean and minimal navigation design
- Easy to customize
- Responsive structure
- Ready to use with React applications

### Usage

```javascript
import Studios3000Nav from './studios3000_nav';

function App() {
  return (
    <div>
      <Studios3000Nav />
      {/* Your content here */}
    </div>
  );
}
```
